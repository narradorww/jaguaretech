# Jaguaretech

> Estudio de software enfocado en mobile, IA aplicada y desarrollo de software personalizado.

## Quiénes Somos
Jaguaretech es una software development company que transforma visiones en apps mobile-first, plataformas web y sistemas inteligentes. Entregamos AI software development, integración de sistemas y staff augmentation services con squads senior.

## Servicios
- **Apps Mobile**: React Native, Flutter, Swift/Kotlin. Arquitectura offline-first.
- **AI Software Development**: LLMs, agentes, automatización, visión computacional.
- **Plataformas Web**: Next.js, dashboards de alto rendimiento, APIs escalables.
- **Integración de Sistemas**: ERPs, CRMs, pagos, datos en tiempo real.
- **Staff Augmentation Services**: ingenieros y especialistas para acelerar entregas.
